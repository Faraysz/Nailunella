## 🎯 Tentang Proyek Ini

**NailDesk** adalah template *Admin Dashboard* yang dikustomisasi khusus untuk kebutuhan manajemen bisnis **Jasa Nail Art**. Proyek ini dikembangkan berdasarkan template *InApp Free Inventory Admin Dashboard* (oleh CodesCandy/ThemeWagon) yang telah diadaptasi agar relevan dengan alur kerja salon atau studio nail art.

Dashboard ini menyediakan antarmuka yang bersih, responsif, dan intuitif untuk memantau jadwal pelanggan, mengelola stok bahan (kuteks, aksesoris, dll.), serta melihat ringkasan pendapatan harian atau bulanan.

---

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---------|-------------|
| 📊 **Dashboard Overview** | Ringkasan visual pendapatan, jumlah pelanggan hari ini, dan stok bahan yang menipis. |
| 📦 **Manajemen Inventaris** | Pencatatan stok masuk dan keluar untuk bahan habis pakai (kuteks, kuku palsu, aksesoris). |
| 📅 **Jadwal & Booking** | Tampilan kalender atau tabel untuk melacak jadwal janji temu (*appointment*) pelanggan. |
| 📱 **Fully Responsive** | Tampilan optimal di desktop, tablet, dan mobile berkat framework Bootstrap 5. |
| 🎨 **Mudah Dikustomisasi** | Struktur SCSS yang terorganisir, memungkinkan penggantian warna tema (misal: warna brand salon) dengan mudah. |

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (React Framework untuk rendering yang cepat)
- **Styling**: [Bootstrap 5](https://getbootstrap.com/) + [SCSS](https://sass-lang.com/) (Untuk utilitas kelas dan kustomisasi tema yang mendalam)
- **Bahasa**: JavaScript / HTML
- **Package Manager**: npm / yarn / pnpm / bun
